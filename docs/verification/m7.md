## Lap records as DeadRally keeps them (the owner's choice)

The owner asked for every lap record to be kept and saved, the original's faults fixed, and the Arena's laps kept as the Arena's. As the Windows version (`Game::as_the_windows_version`, every run above) DeadRally still does as the original.

- **Written as the race ends:** the record of the player's car on the race's circuit is kept when the race ends, and `dr.cfg` is handed to the frontend to write then, without the `rand()` the original's writes draw (`a_lap_record_is_written_to_dr_cfg_as_the_race_ends`: the leader turn's 00:31.07 on Holocaust, every record slow, is the one record changed). A window closed after a race no longer loses it.
- **The won Arena:** it ends the game without the statistics, where the original keeps records, so its lap was never kept; now it is (`a_lap_in_the_arena_is_the_arena_s_record_and_written_as_it_ends`).
- **The Arena's own records:** the original reads and writes circuit 0's (Suburbia's). DeadRally keeps six records of the Arena's, one for each car, after the original's bytes in its own `dr.cfg` (`the_arena_keeps_lap_records_of_its_own_after_the_original_s_bytes`); a file without them stays in the original's format. The race's record call and the statistics' best lap ever read them, and the Hall of Fame's records have a page for the Arena after the eighteen circuits, its name the statistics' heading for the Arena without the colon and its snapshot the race preview's picture of it shrunk (checked by eye in the game, then `the_records_end_with_the_arena_s_own_page`).
- **Every other way a race ends keeps its record already:** a race abandoned gives the player the last place, and a lapped or wrecked player's laps count; each goes through the statistics in the original as well.

## What the original does that the decompilations do not say

- **Its OpenGL picture filters the 640x480 screens always** (`GL_LINEAR`, 0x43B898), and the 320x200 ones only with `-smooth` or after F12 (0x43B6A2). DeadRally's scaled picture now does the same.
- **Its software picture with `-smooth`** (0x43BA99) is not filtered by the system: see the spec's section 3.

## Review

A fresh review of the branch found nothing Critical. Its four Important findings were fixed, with tests that failed first where code could test them:
- **The folder dialog only where choosing can help:** when no folder is given anywhere, or the config file's is not the game (`the_folder_dialog_is_offered_only_when_choosing_can_help`). A broken config file or a wrong `--data` is reported as it is. A display option that is not true or false is a warning, so it no longer stops the game finding its data (`a_display_option_that_is_not_true_or_false_is_a_warning`). The config file's warnings now show in a message box.
- **No console window on Windows:** the release build is a Windows program, not a console one; the release workflow's smoke test still reads its output.
- **The README's way past Gatekeeper and SmartScreen:** on macOS 15, System Settings' "Open Anyway"; on Windows, "More info", then "Run anyway".
- **Errors a player can see:** the errors from the options and the window or sound setup show in a message box. Finder's `-psn_` argument is ignored (`macos_launch_arguments_are_ignored`).

These minor findings were fixed as well:
- the release workflow's Pack step failing with `package.sh`;
- Quit ending the wait for the dialog;
- the warning when the config file cannot be written;
- the README's Esc, which asks first;
- the README's links, which point at GitHub from inside a package;
- the comments saying why the picture tests matter.

Three of its minors were fixed after the review:
- a wrong folder chosen now says that the next start asks again;
- `spike-check.sh`'s shots are named for what they show, the F12 shot on the 320x200 screen;
- the macOS app's version is the tag's numbers, or 0.0.0 for a development build.

Deferred minors:
- **`save_data_path` loses the file's comments and order:** its documentation says so, and it only runs when the file did not name a usable folder.
- **Column 639 when F12 turns smoothing on:** in the original it keeps the doubled picture's last column, which DeadRally shows black; it is one pixel wide.
