# DeadRally

Original Death Rally reincarnation for modern systems: a clean, native,
64-bit reimplementation of *Death Rally for Windows* (Remedy, 2009) for
Windows, macOS and Linux.

**Status:** planning. Start with [docs/PROJECT_BRIEF.md](docs/PROJECT_BRIEF.md).
It covers the goal, the approach, the references, the roadmap and the first
steps.

The repository contains no game data. You need your own copy of the game
(Death Rally on Steam, or Remedy's 2009 freeware release).
